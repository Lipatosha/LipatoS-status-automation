# LipatoS — Статусы
Полностью переписанный модуль для **Foundry VTT 14 / D&D5e 6.0.6 (Legacy 2014)**. Сохранён ID `lipatos-status-automation`: старый модуль заменяется обновлением.

## Поведение
- Для игрока кнопка статусов в HUD токена называется **«Статусы»**. Оригинальная кнопка Foundry сохраняет штатную иконку; название «Статусы» показывается только при наведении. По нажатию вместо списка всех состояний она открывает только активные состояния/эффекты его персонажа, с иконкой, названием, источником и оставшейся длительностью, если она задана. При отсутствии срока действия подпись «Нет» не показывается.
- При наведении или фокусе появляется тёмная подсказка как у D&D5e. Все 40 встроенных статусов и маркеров D&D5e 6.x имеют собственные русские описания, адаптированные под Legacy 2014: `bleeding`, `blinded`, `burning`, `charmed`, `cursed`, `dehydration`, `deafened`, `diseased`, `exhaustion`, `falling`, `frightened`, `grappled`, `incapacitated`, `invisible`, `malnutrition`, `paralyzed`, `petrified`, `poisoned`, `prone`, `restrained`, `silenced`, `stunned`, `suffocation`, `surprised`, `transformed`, `unconscious`, `burrowing`, `concentrating`, `coverHalf`, `coverThreeQuarters`, `coverTotal`, `dead`, `dodging`, `ethereal`, `flying`, `hiding`, `hovering`, `marked`, `sleeping`, `stable`. Системные англоязычные справочные страницы не подменяют эти тексты. Для сторонних статусов без словаря используется описание их источника.
- Окно статусов открывается по нажатию штатной кнопки; не использует отдельную кнопку с текстом. В стандартной вкладке эффектов листа игрок видит только список. Навигация переименована в **«Статусы»**; для альтернативных листов добавляется одноимённая кнопка.
- Игрок не может добавлять, отключать, изменять или удалять Actor Active Effects в HUD и листе: клиентские `preCreate/preUpdate/preDeleteActiveEffect` блокируют попытки. Изменения массива эффектов через Actor и значков Token также блокируются. Исключение — системный псевдостатус `falling`: D&D5e 6.0.6 автоматически создаёт и снимает его при движении токена, поэтому эта штатная автоматизация не блокируется. Вручную выбирать статусы игрок по-прежнему не может.
- ГМ использует штатный HUD и системные редакторы без ограничений. При наведении на иконки в стандартной сетке выбора статусов появляется полная русская подсказка с правилами (как у игрока); маленькая штатная подсказка с повторяющимся названием отключена только у иконок статусов ГМа; ЛКМ и ПКМ продолжают работать штатно. Ни разметка, ни иконки, ни обработчики наложения состояний ГМ не заменяются. Уже имеющиеся Active Effects и статусы не изменяются при обновлении.

## Важно
Ветка v2 — смена назначения: **бывшие правила `flags.lipatos-status-automation.rules`, периодические урон/лечение, повторные спасброски, реакция на использование предмета и программный API apply/configureItem больше не исполняются**. Удалять старые флаги с предметов не требуется, они инертны. Встроенная D&D5e обработка эффектов продолжает работать; действия, которые требуют изменения Actor ActiveEffect с клиента игрока, теперь выполняет ГМ. Клиентский запрет модуля не является серверной системой защиты от целенаправленного обхода или отключения модуля.

Проверка: GitHub Actions запускает `node --check` и smoke-тест на список активных состояний, запреты для игрока и полномочия ГМ. Проверка непосредственно в интерфейсе Foundry после обновления по-прежнему нужна.

## Установка
Манифест: https://github.com/Lipatosha/LipatoS-status-automation/releases/latest/download/module.json
Обновите модуль, полностью перезапустите мир и переподключите игроков. Выпуск формируется в GitHub Actions. Автор: LipatoS.
