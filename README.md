# LipatoS — Статусы
Полностью переписанный модуль для **Foundry VTT 14 / D&D5e 6.0.5 (Legacy 2014)**. Сохранён ID `lipatos-status-automation`: старый модуль заменяется обновлением.

## Поведение
- Для игрока кнопка статусов в HUD токена называется **«Статусы»**. Вместо списка всех состояний она открывает только активные состояния/эффекты его персонажа, с иконкой, названием, источником и оставшейся длительностью.
- При наведении или фокусе появляется тёмная подсказка как у D&D5e. Сначала загружается доступная игроку страница правил из `CONFIG.DND5E.conditionTypes[statusId].reference`; если она недоступна, используется локальное описание известных состояний Legacy или описание Active Effect.
- В стандартной вкладке эффектов листа игрок видит только список. Навигация переименована в **«Статусы»**; для альтернативных листов добавляется одноимённая кнопка.
- Игрок не может добавлять, отключать, изменять или удалять Actor Active Effects в HUD и листе: клиентские `preCreate/preUpdate/preDeleteActiveEffect` блокируют попытки. Изменения массива эффектов через Actor и значков Token также блокируются.
- ГМ использует штатный HUD и системные редакторы без ограничений. Уже имеющиеся Active Effects и статусы не изменяются при обновлении.

## Важно
Ветка v2 — смена назначения: **бывшие правила `flags.lipatos-status-automation.rules`, периодические урон/лечение, повторные спасброски, реакция на использование предмета и программный API apply/configureItem больше не исполняются**. Удалять старые флаги с предметов не требуется, они инертны. Встроенная D&D5e обработка эффектов продолжает работать; действия, которые требуют изменения Actor ActiveEffect с клиента игрока, теперь выполняет ГМ. Клиентский запрет модуля не является серверной системой защиты от целенаправленного обхода или отключения модуля.

Проверка: GitHub Actions запускает `node --check` и smoke-тест на список активных состояний, запреты для игрока и полномочия ГМ. Проверка непосредственно в интерфейсе Foundry после обновления по-прежнему нужна.

## Установка
Манифест: https://github.com/Lipatosha/LipatoS-status-automation/releases/latest/download/module.json
Обновите модуль, полностью перезапустите мир и переподключите игроков. Выпуск формируется в GitHub Actions. Автор: LipatoS.
