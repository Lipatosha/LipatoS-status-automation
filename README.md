# LipatoS — Автоматизация состояний и эффектов

Модуль для **Foundry VTT 14 / D&D5e 6.0.5**. Отдельный модуль, без обязательных зависимостей от Midi-QOL, DAE, Character Forge или Laaru. Использует штатные Active Effects и значки состояний D&D5e.

## Установка

Манифест: https://github.com/Lipatosha/LipatoS-status-automation/releases/latest/download/module.json

Включите модуль в мире с системой D&D5e 6.0.5. Для автоматического применения эффектов и обработки ходов требуется **один активный ГМ**. Все изменения целей выполняет первый активный ГМ по ID; игроки могут использовать принадлежащие им предметы.

## Настройка

1. Откройте лист заклинания, оружия или способности, затем **«Автоэффекты»** в заголовке (доступно ГМ).
2. Если у предмета несколько действий (Activities), выберите нужное.
3. Включите правило, выберите состояние (например, **Отравлен**), условие применения, количество срабатываний, начало/конец хода, формулу урона, тип и повторный спасбросок.
4. Сохраните. Правило хранится в flags предмета: `flags.lipatos-status-automation.rules.<activityId>`.
5. Выберите цели обычным способом Foundry (T), используйте нужное действие предмета. Для атак можно выбрать **«После броска атаки при попадании»**; для действий без атаки — «При использовании». Если D&D5e сама накладывает Active Effect после спасброска, выберите режим **«При штатном наложении эффекта D&D5e»**.

**Пример:** «Ядовитые когти»: состояние `poisoned`, режим **после попадания**, два срабатывания, начало хода цели, `1d4`, тип `poison`, повторный спасбросок Телосложения со Сл 12, успешный спасбросок завершает эффект. При успешном попадании создаётся Active Effect на цели. В начале её двух следующих ходов выполняются настроенные проверки; после последнего срабатывания эффект удаляется.

В режиме «При штатном наложении» модуль подхватывает созданный системой Active Effect предмета и добавляет к нему периодическую логику; сам повторно его не накладывает. Для корректного сопоставления выберите соответствующее Activity и настройте его штатный Active Effect.

В настройке «После попадания» используется результат броска атаки и текущая КД выбранных целей, включая натуральные 1/20. Это **не** обработчик реакций, укрытия и последующего изменения КД: в таких случаях результат скорректирует ГМ. Сначала выбирайте цели; модуль не ищет их по описанию предмета.

## Что делает версия 1.0.0

- Сохраняет независимые эффекты от разных источников; повторное наложение того же правила обновляет его длительность.
- Проверяет иммунитет цели к указанному состоянию.
- Накладывает стандартные значки через Active Effect с `statuses`, не вмешиваясь в эффекты других модулей и обычные системные эффекты.
- Срабатывает на начале или конце хода цели либо источника; считает оставшиеся срабатывания и автоматически удаляет свой эффект.
- Делает повторный спасбросок, применяет результат (снять эффект, половина урона, без урона либо полный урон).
- Бросает формулу, публикует бросок в чат, применяет типизированный урон через D&D5e Actor.applyDamage (с сопротивлениями/иммунитетом системы) либо лечение через тип `healing`.
- По выбору ГМ вызывает перед срабатыванием окно у владельца персонажа; после подтверждения ГМ инициирует системный спасбросок. Если владелец не отвечает, через 45 секунд обработка продолжается у ГМ.
- Хранит отметку уже обработанного хода в эффекте, чтобы не наносить повторный урон из-за повторного hook-события.
- Поддерживает применение игроком к выбранной цели через встроенный сокет с проверкой владения исходным предметом; записи в документы выполняет ГМ.

Обычная система D&D5e уже умеет применять встроенные Active Effects и часть условий истечения у Activities. Модуль **не дублирует их и не парсит естественный текст**: для периодического урона и дополнительных эффектов нужно настроить правило на соответствующем действии. Режим «При использовании» не определяет, прошёл ли первоначальный спасбросок; для таких способностей используйте режим «При штатном наложении» и задайте периодическую логику для того же Activity. Модуль не предназначен для полноценных автоматических площадных атак, сложных концентрационных связей и исполнения произвольных скриптов из текстов.

Если бой не начат, эффект создаётся, но отсчёт срабатываний начнётся при старте боя, к которому он привязан. Для безбоевых длительностей в минутах/часах используйте штатную длительность D&D5e.

## Программный интерфейс

После `ready`:

```js
const api = game.modules.get("lipatos-status-automation").api;
await api.configureItem(item); // ГМ: редактор на выбранном предмете
await api.apply(targetActor, sourceItem, {
  name: "Ядовитые когти",
  status: "poisoned",
  rounds: 2,
  timing: "start",
  formula: "1d4",
  damageType: "poison",
  saveAbility: "con",
  dc: 12,
  success: "end",
  prompt: true
}, "my-activity-id"); // ГМ: создать эффект программно
```

Поля `flags` пригодны для JSON-импорта актёров и вещей через LipatoS — Импорт актёров. Пример см. в `examples/poison-rule.json`; встраивайте только часть `flags` в соответствующий **Item**.
