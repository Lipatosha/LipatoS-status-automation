# Изменения

## 1.0.1

- Поддержка периодической логики для штатно применённых D&D5e Active Effects (включая эффект после спасброска).
- Окно проверки у владельца персонажа включено по умолчанию для новых правил.
- Исправлена обработка иммунитета к состоянию без потери периодического урона.
- Добавлены smoke-тесты двойной обработки, времени действия и повторного применения.

## 1.0.0

- Первоначальная система правил для Activities предметов.
- Редактор состояний, хода срабатывания, периодического урона и повторных спасбросков.
- Стандартные Active Effects, сохранение длительности, независимый учёт источников.
- Проверка попадания для атаки, сокет владельца/ГМ, уведомления и журнал бросков.
- Публикация ZIP и манифеста через GitHub Actions.
