# Изменения

## 2.0.2
- Убрана бессмысленная подпись «Нет» под активными статусами без установленной длительности.
- Установленное время или оставшиеся раунды по-прежнему отображаются.

## 2.0.1
- Восстановлена штатная иконка кнопки выбора статуса у игрока, без постоянной надписи.
- Обработчик нажатия использует оригинальный элемент и открывает доступный только для чтения список.
- Панель вынесена в body, исправлены интерактивность, позиционирование и закрытие.


## 2.0.0 — Полная переработка
- Новый статусный интерфейс игрока: только активные состояния и эффекты, кнопка «Статусы».
- Подсказки описаний через правила D&D5e и русские описания Legacy.
- Запрет игрокам менять Actor Active Effects, статусы токена и пользоваться меню их назначения.
- ГМ сохраняет полный штатный доступ.
- Прекращена работа старого движка периодических эффектов; ID репозитория и модуля сохранены.

## 1.0.2 (архивная версия)
- Старая автоматизация периодического урона и длительностей, теперь выведена из эксплуатации.
